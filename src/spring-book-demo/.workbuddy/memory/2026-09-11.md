## spring-book-demo 全量代码审查

- 用 javac 实测确认：**项目当前编译不通过**。`service/BookService.java:76` 声明返回 `Integer`，却 `return result == 1 ? "" : "数据更新失败";`（String 无法转换为 Integer）。target/classes 中的 BookService.class 是 13:00 的旧产物，源码 16:14 改过，最后一次编辑从未编译。
- 修好类型后仍有 NPE 风险：`Integer result` 可能为 null（service 吞掉异常后返回 null），`result == 1` 拆箱会 NPE。`BookController.addBook()` 的 `result == 1 ? "" : "插入图书失败"` 同样有此问题。
- 前端 bug：`login.html` 的 `location.href = "book_list.html"` 写在 `$.ajax` 外面，无条件跳转 → 登录校验形同虚设。
- `book_update.html` 的 `update()` 只 alert，未发请求；页面也没按 bookId 回填数据 → 修改功能未实现。
- `book_list.html` 批量删除调用 `/book/batchDeleteBook`，后端无此接口；删除/批删的结果判断用 `result.code == 200 && result.data == ""`，后端返回裸字符串 → 永远提示失败。
- `mapper/BookInfoMapper.xml` 的 `<update>` 里在 `<set>` 内又写了 `set book_name = ...` → 生成 `SET SET`；且 publish 与 status 分支之间缺逗号。
- 其他：分页 SQL 无 ORDER BY、offset 未做边界校验；`BookInfo.uptatteTime` 拼写错误导致 update_time 映射不上；`BookStatus.DETETED` 拼写错误；登录未写 session、/book/* 无鉴权、密码明文比对；`select *`；前端字符串拼接存在 XSS；查询列名 `count` 建议加反引号。
- 配置/依赖：`application.yml` 明文 DB 密码 + 中文注释已被保存成 `?`（编码丢失）；`mybatis-spring-boot-starter` 为 3.0.3（baseline Boot 3.2），与 Boot 3.5.7 应对齐到 **3.0.5**（官方 baseline Spring Boot 3.5.x）。
- 结论：先修编译错误 + 登录跳转，再补 update/batchDelete 两条链路，最后做统一返回体 + 全局异常处理。

## 第三轮：强制登录 + 统一返回体（20:32 完成，编译通过）

用户自己在中途改过代码，动手前先核对了实际状态，注意两点：

**新增文件**
